## 5. [fastapi/fastapi](https://github.com/fastapi/fastapi)

**项目简介：** 基于 Python 类型提示构建 Web API 的框架，接收函数参数声明的类型，经 Pydantic 完成请求数据校验与转换，并自动生成 OpenAPI 文档及 Swagger UI、ReDoc 交互页面。底层基于 Starlette，可通过 uvicorn 运行。

**解决的问题：** 手写参数解析、数据校验与 API 文档同步维护，容易出现接口定义与文档不一致或类型错误。

**使用场景：** 用 Python 类型声明定义 GET、PUT 等 HTTP 接口；让请求体和路径参数自动完成校验并返回错误信息；直接从接口定义生成可在浏览器中调试的 API 文档
