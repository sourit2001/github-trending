## 2. [NVIDIA/OpenShell](https://github.com/NVIDIA/OpenShell)

Rust · ⭐ 19,392 · 893 stars today · License: Apache-2.0

**项目简介：** OpenShell 为自主 AI Agent 提供隔离运行时。用户在策略中声明每个 Agent 可访问的文件、网络和凭证，运行时在每次文件访问、系统调用和网络连接时执行检查，并对策略变更做形式化验证。

**解决的问题：** Agent 需要读文件、装包、调用 API 和使用凭证，但直接授予这些权限会暴露数据与密钥。OpenShell 用策略限定每个 Agent 的访问范围。

**主要功能：** 在隔离沙箱中运行每个 Agent；内核级控制文件访问与系统调用；网络连接经策略检查后才能发出；Agent 不直接接触真实凭证；策略变更前用形式化验证标记风险

**使用场景：** 为多个 AI Agent 分别设定文件与网络访问策略；让 Agent 调用指定端点时由运行时注入凭证；在策略变更生效前拦截新增的高风险访问
